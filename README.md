# سفرنامه

**سفرهای اسنپت، این بار با جزئیات**

تاریخچهٔ سفرهای اسنپ‌ات را به یک گزارش فارسی تبدیل می‌کند: چقدر خرج کردی، کجاها رفتی و کرایهٔ مسیرهای همیشگی‌ات چقدر بالا رفته. همه‌چیز توی مرورگر خودت اجرا می‌شود، با افزونهٔ کروم یا یک سایت استاتیک.

[**سایت و گزارش نمونه**](https://mehdihadizadeh.github.io/safarnameh-extension/) · [**دانلود افزونه**](https://github.com/MehdiHadizadeh/safarnameh-extension/releases/latest)

## چه چیزی نشان می‌دهد

- تعداد سفر، هزینه و مسافت در ۱۲ ماه آخر
- گرانی کرایه در مسیرهای تکراری (مقایسهٔ میانهٔ هر سال)
- جاهایی که بیشتر رفتی، ریتم هفته و پرخرج‌ترین ماه
- تاریخ شمسی، ارقام فارسی، حالت روشن و تیره، و گزارشی که روی موبایل هم راحت خوانده می‌شود

اسنپ فقط حدود ۱۲ ماه تاریخچه می‌دهد، پس گزارش هم همان‌قدر عقب می‌رود.

## حریم خصوصی

سرور ندارد و چیزی ذخیره نمی‌کند. همهٔ تحلیل توی همان صفحه انجام می‌شود و سیاست امنیت محتوا (CSP) با `connect-src 'none'` جلوی هر درخواست بیرونی را می‌گیرد.

افزونه فقط به `https://app.snapp.taxi/*` دسترسی دارد (و `activeTab` و `scripting`). مجوز `storage` را فقط برای رساندن نتیجه به تب گزارش می‌خواهد: دادهٔ `chrome.storage.session` فقط در حافظه می‌ماند و به‌محض باز شدن گزارش پاک می‌شود. کد کوتاه است؛ قبل از اجرا می‌توانی بخوانی.

## نصب

### افزونهٔ کروم

1. فایل zip را از [Releases](../../releases) بگیر و از حالت فشرده دربیار.
2. توی `chrome://extensions` حالت **Developer mode** را روشن کن و با **Load unpacked** همان پوشه را انتخاب کن.
3. وارد [app.snapp.taxi](https://app.snapp.taxi/ride-history) شو، روی آیکن افزونه بزن و **ساخت گزارش** را انتخاب کن.

افزونه از Chrome Web Store آپدیت نمی‌گیرد. نسخهٔ جدید که آمد، zip تازه را جایگزین کن و توی `chrome://extensions` Reload بزن.

### سایت

`index.html` را مستقیم باز کن، یا پوشه را روی یک هاست استاتیک (GitHub Pages، Cloudflare Pages، Netlify) بگذار. بیلد لازم نیست. سایت یک اسکریپت کوچک برای کنسول اسنپ می‌دهد که تاریخچه را به‌صورت فایل JSON ذخیره می‌کند؛ همان فایل را روی صفحه بینداز تا گزارش ساخته شود. اگر فقط می‌خواهی ببینی گزارش چه شکلی است، «دیدن گزارش نمونه» داده‌های ساختگی نشان می‌دهد.

## توسعه

برای ساخت فقط Python 3 لازم است. Node برای تست‌ها و Chrome یا Edge برای ساختن دوبارهٔ تصاویر. بقیه وابستگی‌ای ندارد.

```bash
python build.py                  # dist/ و پوشهٔ افزونه (extension/) را می‌سازد
node --test tests/analyze.test.js
python branding/render.py        # آیکن و تصاویر را از منبع‌های branding/ دوباره می‌سازد
```

بعد از کلون، یک بار `python build.py` را بزن؛ فایل‌های مشترک وارد `extension/` می‌شوند و بعد می‌شود همان پوشه را Load unpacked کرد.

**انتشار نسخهٔ افزونه:** شمارهٔ `version` را در `extension/manifest.json` بالا ببر، commit کن و تگ هم‌نام را push کن (مثلاً برای نسخهٔ `0.1.1` تگ `v0.1.1`). workflow در `.github/workflows/release.yml` تست‌ها را اجرا می‌کند، zip را می‌سازد و به Release اضافه می‌کند. اگر تگ با نسخهٔ manifest یکی نباشد، ساخت متوقف می‌شود.

```bash
git tag v0.1.1 && git push origin v0.1.1
```

### ساختار

```
index.html            صفحهٔ فرود و اسکلت گزارش
assets/analyze.js     موتور تحلیل، توابع خالص و بدون DOM
assets/report.js      نمایش مدل توی گزارش
assets/collector.js   اسکریپت کنسول
assets/demo.js        داده‌های ساختگی گزارش نمونه
extension/            افزونهٔ Manifest V3
branding/             منبع و خروجی آیکن و تصاویر
tests/                تست‌های موتور تحلیل
build.py              اینلاین‌کردن فایل‌ها، ساخت dist و zip افزونه
```

### `analyze.js`

```js
const model = SnappAnalyze.analyze(json); // توی Node هم کار می‌کند: require("./assets/analyze.js")
```

ورودی، پاسخ خام تاریخچهٔ سفر است، به هر شکل رایجش: `[ride]`، `{rides}`، `{data:{rides}}` یا آرایه‌ای از صفحه‌ها. خروجی یک مدل ساده است. این قاعده‌ها را موقع تغییر نگه دار:

- ترتیب ایستگاه‌ها `origin → destination → extra_destination` است و آخری مقصد نهایی است.
- مسافت جمع پاهای مسیر است و به‌صورت تخمین نشان داده می‌شود.
- مکان‌ها با الگوریتم leader و شعاع ۱۵۰ متر دسته می‌شوند، نه single-linkage.
- کرایه‌ها با میانهٔ سالانه مقایسه می‌شوند.
- قیمت‌ها در API ریال‌اند و برای نمایش بر ۱۰ تقسیم می‌شوند. سفر لغوشده در هزینه نمی‌آید.

## مشارکت

Issue و PR خوش‌آمد است. قبل از دست بردن در `analyze.js` قاعده‌های بالا را بخوان. توی Issue و PR هم هیچ‌وقت داده‌های واقعی سفر (آدرس، مختصات، نام راننده) نگذار.

## سلب مسئولیت

این پروژه مستقل است و ارتباطی با اسنپ ندارد. فقط تاریخچهٔ همان کاربری را که وارد شده، از همان endpoint که وب‌اپ اسنپ استفاده می‌کند، می‌خواند. شرایط استفادهٔ اسنپ ممکن است دسترسی خودکار را محدود کرده باشد؛ قبل از استفاده بخوانش.
