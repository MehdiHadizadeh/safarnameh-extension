# سفرنامه

**سال سفرهایت با اسنپ، در هشت کارت**

گزارش فارسی و راست‌به‌چپ از تاریخچهٔ سفرهای اسنپ. کاملاً در مرورگر اجرا می‌شود، به‌صورت سایت استاتیک یا افزونهٔ کروم.

## امکانات

- خلاصهٔ هزینه، مسافت و تعداد سفر در ۱۲ ماه اخیر
- تورم کرایه در مسیرهای تکراری، بر پایهٔ میانهٔ سالانه
- پربازدیدترین مکان‌ها (خوشه‌بندی ۱۵۰ متری)، ریتم هفته، پرخرج‌ترین ماه
- تاریخ جلالی، ارقام فارسی، حالت روشن و تیره، گزارش سازگار با موبایل
- تصویر اشتراک‌گذاری فقط با عددهای کلی
- بدون سرور، بدون ثبت‌نام، بدون آنالیتیکس

## حریم خصوصی

تمام تحلیل محلی و داخل همان صفحه انجام می‌شود. سروری وجود ندارد و چیزی ذخیره نمی‌شود. سیاست امنیت محتوا (CSP) روی `connect-src 'none'` است، پس صفحه نمی‌تواند چیزی بفرستد. افزونه فقط `activeTab`، `scripting` و `https://app.snapp.taxi/*` را می‌خواهد. کد آن‌قدر کوتاه است که پیش از اجرا بخوانیش.

## نصب

### افزونهٔ کروم

1. فایل zip را از [Releases](../../releases) بگیر و باز کن؛ یا `python build.py` را بزن و از `dist/extension` استفاده کن.
2. در `chrome://extensions` گزینهٔ **Developer mode** را روشن کن، **Load unpacked** را بزن و پوشه را انتخاب کن.
3. وارد [app.snapp.taxi](https://app.snapp.taxi/ride-history) شو، روی آیکن افزونه بزن و **ساخت گزارش** را انتخاب کن.

### نسخهٔ وب

`index.html` را مستقیم باز کن، یا پوشه را روی هر هاست استاتیک (GitHub Pages، Cloudflare Pages، Netlify) بگذار. نیازی به بیلد نیست. صفحه سه قدم کار با کنسول را نشان می‌دهد و یک گزارش نمونه با دادهٔ ساختگی هم دارد.

## توسعه

نیازمندی: Python 3 برای بیلد، و Chrome یا Edge برای ساخت دوبارهٔ تصاویر. وابستگی زمان اجرا ندارد.

```bash
python build.py             # dist/index.html، dist/artifact.html، dist/extension و zip افزونه
python branding/render.py  # آیکن‌ها و تصاویر اشتراک از منبع‌های branding/
```

انتشار نسخه: شمارهٔ `extension/manifest.json` را بالا ببر و یک تگ پوش کن. workflow در `.github/workflows/release.yml` zip را می‌سازد و به Release اضافه می‌کند.

```bash
git tag v0.1.0 && git push origin v0.1.0
```

### ساختار

```
index.html            صفحهٔ فرود و اسکلت گزارش
assets/analyze.js     موتور تحلیل، توابع خالص، بدون DOM
assets/report.js      رندر مدل در گزارش
assets/collector.js   اسکریپت جمع‌آوری برای کنسول
assets/demo.js        دادهٔ نمونهٔ ساختگی
extension/            افزونهٔ Manifest V3
branding/            منبع و خروجی آیکن و تصاویر اشتراک
build.py              اینلاین‌کردن فایل‌ها و ساخت dist و zip افزونه
```

### `analyze.js`

```js
const model = SnappAnalyze.analyze(json); // در Node هم کار می‌کند: require("./assets/analyze.js")
```

ورودی پاسخ خام تاریخچهٔ سفر در هر شکل رایج است (`[ride]`، `{rides}`، `{data:{rides}}` یا آرایه‌ای از صفحه‌ها) و خروجی یک مدل ساده. اصولی که باید حفظ شوند:

- ترتیب ایستگاه‌ها `origin → destination → extra_destination` است و آخری مقصد نهایی است.
- مسافت جمع پاهای مسیر است و به‌صورت تخمین نشان داده می‌شود.
- مکان‌ها با الگوریتم leader و شعاع ۱۵۰ متر خوشه می‌شوند، نه single-linkage.
- مقایسهٔ کرایه با میانهٔ سالانه است.
- قیمت‌ها ریال‌اند و برای نمایش بر ۱۰ تقسیم می‌شوند؛ سفر لغوشده در هزینه نمی‌آید.

## مشارکت

Issue و PR خوش‌آمد است. پیش از تغییر در `analyze.js` اصول بالا را بخوان، و دادهٔ واقعی سفر (آدرس، مختصات، نام) را هرگز در Issue یا PR نگذار.

## سلب مسئولیت

پروژه‌ای مستقل است و ربطی به اسنپ ندارد و از سوی آن تأیید نشده. فقط تاریخچهٔ کاربرِ واردشده را از همان endpoint که وب‌اپ اسنپ استفاده می‌کند می‌خواند. پیش از استفاده یا انتشار، شرایط استفادهٔ اسنپ را بخوان.
